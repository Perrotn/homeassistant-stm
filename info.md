Home Assistant integration for the **Société de transport de Montréal (STM)**.

## Features

- 🚇 Real-time service status for all **4 metro lines**
- 🔔 **Disruption alerts** with estimated resumption time
- 🚌 **Next departures** at any stop with real stop names, destinations and delays
- 🚍 Vehicle positions with speed and occupancy data
- 📡 Official STM API (free key required)

## Requirements

Free API key from [portail.developpeurs.stm.info](https://portail.developpeurs.stm.info/apihub)
